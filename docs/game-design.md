# Diseño de juego

CYBERCBA 2077 es una campaña de ciencia ficción en Neo-Córdoba, 2077. La UI es diegética: no muestra tests, tickets ni nombres de estructuras. La v0.1.0 dura un prólogo breve: refugio, señal imposible, exterior bajo lluvia, ruta de habilidad, entrada de Neometro y anuncio de la siguiente release.

Emma usa una terminal para abrir su ruta; Magga enfrenta un dron y fuerza la alternativa física. Ambas rutas duran una interacción principal, presentan evidencia distinta y convergen antes del final. El mundo usa formas procedurales, neón, lluvia y arquitectura industrial para conservar una identidad coherente sin assets licenciados externamente.
