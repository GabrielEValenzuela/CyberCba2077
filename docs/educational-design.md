# Diseno educativo

Protocolo de Emergencia representa solicitudes que llegan a una red urbana. El jugador observa el orden, predice `dequeue()`, ejecuta, pide pista, retrocede o reinicia. El inspector muestra size, capacity, front, rear, proxima operacion e invariante FIFO. Resultados conectan precision, intentos, pistas y creditos con lo sucedido; la velocidad no define la recompensa.
